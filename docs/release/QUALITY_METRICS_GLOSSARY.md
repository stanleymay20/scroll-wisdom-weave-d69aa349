# ScrollLibrary quality metrics glossary

## Chief Editor score

AI-assisted developmental/editorial assessment against ScrollLibrary's internal rubric. It measures structure, cognitive depth, rigor, pedagogy and AI-detectability risk. It is not human peer review or external accreditation.

## Publishability score

Deterministic defect score over the current manuscript: generation completeness, content artifacts, rendering risk, citation/evidence cues, technical issues and export integrity. A high score means fewer detected mechanical/integrity defects; it does not alone measure literary excellence.

## Human review score

Independent reviewer assessment using the controlled 1–10 rubric in the qualification template. This is required for generation-mode near-10 qualification and is distinct from ordinary manuscript certification.

## Production render certification

Inspection of the actual canonical rendered artifact rather than source text alone. A pass demonstrates that the produced file meets ScrollLibrary's current production-render checks; it does not guarantee acceptance by an external retailer.

## Evidence attestation

Current-scope verification that governed factual material has passed the applicable source/claim integrity process. An evidence pass is not a universal guarantee that every statement is true; it is proof that the defined verification contract passed for the current manuscript scope.

## ScrollLibrary Press Certified

A controlled product quality state requiring the strict thresholds and current attestations defined in `SCROLLLIBRARY_CONTENT_QUALITY_STANDARD.md`. It is not a promise of commercial success, retailer acceptance, academic accreditation or peer review.
