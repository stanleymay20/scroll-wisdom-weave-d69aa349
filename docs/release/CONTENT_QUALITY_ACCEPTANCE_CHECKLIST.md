# Content quality acceptance checklist

A release reviewer should answer every item before allowing a stronger quality claim.

## Draft -> Verified

- [ ] All declared chapters generated and present.
- [ ] No generation placeholders/editorial leakage.
- [ ] Deterministic QA current for manuscript scope.
- [ ] Governed evidence checks pass where required.
- [ ] Technical code audits pass where applicable.
- [ ] Structural/rights attestations pass where applicable.
- [ ] Canonical production render passes.
- [ ] No stale attestations after manuscript edits.

## Verified -> ScrollLibrary Press Certified

- [ ] Chief Editor overall >=95.
- [ ] Structural >=90.
- [ ] Academic/cognitive rigor >=90.
- [ ] Pedagogical >=90.
- [ ] Publishability >=98.
- [ ] Publishability blockers = 0.
- [ ] Publishability warnings = 0.
- [ ] Production blockers = 0.
- [ ] Evidence/technical/rights blockers = 0 where applicable.
- [ ] Exact current manuscript scope hash recorded.

## Generation-route marketing qualification

- [ ] >=5 complete representative books.
- [ ] >=3 independently human-reviewed passing books.
- [ ] Human overall average >=9.5/10.
- [ ] Every human dimension >=9.0/10.
- [ ] Critical issues = 0.
- [ ] Provider/model and prompt versions recorded.
- [ ] Regeneration/failure rate within policy.
- [ ] Tier/model route matches the route being advertised.

If any required item is unchecked, the stronger claim remains fail-closed.
