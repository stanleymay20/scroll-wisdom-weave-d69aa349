# Generation quality failure accounting

Empirical qualification must count attempted generations, not only successful samples.

Record for each corpus run:

- attempts started;
- provider failures/timeouts;
- incomplete books;
- regeneration count;
- automated repair passes;
- books reaching human review;
- books passing machine gates;
- books passing human review.

A route that produces one excellent manuscript after many discarded failures is not equivalent to a route that reliably produces excellent manuscripts on the first or bounded repair attempts.
