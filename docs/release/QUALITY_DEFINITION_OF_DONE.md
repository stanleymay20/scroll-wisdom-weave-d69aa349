# Content quality definition of done

This branch is not done merely because documents exist.

Definition of done:

- policy scripts run in CI;
- pricing semantics are reflected in live-source UI copy;
- bundle economics are rational and server/UI catalogues agree;
- evidence governance covers intended factual categories;
- strict certification is represented as a server-owned state or remains visibly fail-closed rather than inferred from ordinary editorial eligibility;
- tests cover the new contracts;
- exact-head CI is green;
- branch is reviewed and merged intentionally;
- production is later redeployed/verified through Lovable.
