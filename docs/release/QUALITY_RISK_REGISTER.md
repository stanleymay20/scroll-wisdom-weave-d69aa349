# Content quality risk register

| Risk | Impact | Control |
| --- | --- | --- |
| Ordinary 78/100 editorial pass mistaken for near-10 quality | Overclaim / customer disappointment | Three-state doctrine; strict Press Certified threshold |
| One good chapter mistaken for whole-book proof | Weak empirical evidence | Five-book corpus + complete-book human review |
| Pro evidence inherited to Creator | Unsupported tier claim | Per-route qualification |
| Model/prompt drift after qualification | Silent quality regression | Requalification policy |
| Projects interpreted as full long books | Pricing disappointment | Shared-word-pool disclosure |
| Audio credits interpreted as audiobook count | Pricing disappointment | Display narration minutes |
| Bundle costs more than components | Buyer distrust | Bundle-value invariant |
| $399 service vague | Refund/support risk | Explicit Assisted Launch scope |
| Marketplace fee advertised while marketplace closed | Unavailable paid benefit | Conditional marketplace copy |
| Repo gate assumed deployed | Production mismatch | Lovable-controlled deployment verification |
