# Quality evidence policy

Admissible evidence for a near-10 generation-route qualification must come from real complete generated manuscripts and current-scope audits/reviews.

Not admissible as sole proof:

- unit tests;
- mocked E2E responses;
- prompt text;
- architecture diagrams;
- one successful chapter;
- model reputation;
- cherry-picked excerpts;
- self-reported scores without review evidence;
- stale reviews from an earlier manuscript hash.

Machine evidence and human evidence complement each other. Machine gates prove repeatable contract compliance; independent human review evaluates whole-book usefulness, voice, coherence and publication usability.
