# Quality reliability metrics

For each qualified route, report at minimum:

- first-pass completion rate;
- machine-gate pass rate before repair;
- machine-gate pass rate after bounded repair;
- mean and maximum repair passes;
- human-review pass rate;
- mean human overall score;
- minimum human dimension score;
- critical issue rate;
- regeneration rate;
- provider failure rate.

Do not publish only the average score; reliability and tail failures matter to customer experience.
